# NeighborGoods - Local Borrowing Network Frontend

This is the React Vite frontend application for **NeighborGoods** - a hyper-local, peer-to-peer inventory sharing platform for high-trust communities.

## Tech Stack
- React
- Vite
- Axios
- Vanilla CSS / Modern UI

## Setup and Running

1. Install dependencies:
   ```bash
   npm install
   ```

2. Configure environment variables in `.env` (copy from `.env.example` or configure API endpoint).

3. Start development server:
   ```bash
   npm run dev
   ```

## Deployment
Deployed on Vercel using `VITE_API_URL` pointing to the live Render backend api.
